## 1. 분위기

아주 옅은 민트 바탕 위에 흰 카드가 살짝 떠 있는, 갓 씻은 채소처럼 깔끔하고 신선한 화면. 진한 초록은 강조할 때만 써요.

## 2. 색 (2단계)

| 토큰 | 값 | 쓰는 곳 |
|---|---|---|
| `--canvas` | #F4FAF6 | 페이지 바탕 (아주 옅은 민트) |
| `--card` | #FFFFFF | 카드·냉장고·패널·요약 줄 (흰색 + `--shadow-card`) |
| `--surface-soft` | #F4FAF6 | 흰 카드 안의 재료 타일, 내 재료 칩 |
| `--surface-card` | #EAF5EE | 레시피 카드 머리, 반영 피드백 박스, 회차 표시 |
| `--surface-strong` | #DCEBE1 | 비활성 버튼 |
| `--surface-dark` | #12261A | 토스트, "해 먹었어요" 안내 |
| `--hairline` / `--hairline-soft` | #E1ECE5 / #EDF3EF | 1px 테두리 / 구분선 |
| `--accent` | #16A34A | **강조 전용**: 선택 테두리, 체크 원, 신선도 바(초록). 흰 글자를 올리지 않음(대비 3.3:1) |
| `--primary` | #15803D | 주 버튼 바탕(흰 글자 5.0:1), 초록 글자·아이콘 |
| `--primary-active` | #116A32 | 주 버튼 누름 |
| `--primary-tint` | #DCFCE7 | 선택된 타일·칩, 추천 이유, 달라진 점 |
| `--ink` / `--body` / `--muted` | #0F1F17 / #2B3A31 / #5A6B61 | 제목 / 본문 / 보조 글자 |
| `--honey*` | #D9A400 · #FBF1CF · #7A5B00 | 꿀조합 박스 전용 (노란 금색) |
| D-day 색 | 빨강·주황·초록 | 기획안 1-6 규칙. **테마와 상관없이 바꾸지 않음** |

- 그림자 `--shadow-card`: `0 1px 2px rgba(15,31,23,.05), 0 4px 14px rgba(15,31,23,.06)` — 흰 카드에만
- 글자 대비는 모두 4.5:1 이상 (보조 글자 5.4:1, 주 버튼 5.0:1)

## 4. 모양 · 여백

- 모서리: 입력 8px · 버튼 10px · 타일·박스 12px · 패널 16px · 카드·냉장고 20px · 칩·배지 완전 둥글게
- 버튼 높이 52px, 칩 36px, 아이콘 버튼 44px 원형
- 화면 좌우 여백 20px, 카드 안쪽 20px, 기준 폭 390px · 최대 480px
- 깊이: 민트 바탕 → 흰 카드(옅은 그림자) → 카드 안 민트 타일

## 5. 구성 요소

- **주 버튼**: #15803D 채움 + 흰 글자. 화면당 1개
- **보조 버튼**: 흰 바탕 + 얇은 테두리 + 잉크 글자 (아이콘만 초록)
- **재료 타일**: 흰 냉장고 카드 안의 민트 타일. 아래에 **신선도 바** — `D-9` 글자 + 4px 바, 채움 = 남은 일수 ÷ 14일(14일 이상은 꽉 참, 모든 재료 같은 기준이라 바 길이 순서 = 남은 일수 순서, 날짜를 바꾸면 바로 반영. 3일=21%, 7일=50%). 바 색은 D-day 규칙(빨강·주황·초록)
  - 선택: `primary-tint` + #16A34A 테두리 + 초록 체크 원
  - **기한 지남**: 타일 내용 투명도 60% + 빨간 테두리 1줄, 바 0%, 글자 "기한 지남"
- **레시피 카드**: 흰색 + 옅은 그림자, 머리 띠 `surface-card` + 얇은 선 아이콘, 이름은 명조. 카드 안 재료 칩은 D-day 알약 유지
- **추천 이유**: `primary-tint` 박스 / **꿀조합**: `honey-bg` 박스
- **해 먹었어요 안내 · 토스트**: 어두운 면 + 밝은 글자
- **하단 고정 바**: 바탕색 92% + 흐림 효과

## 6. 움직임

- 시작 화면: 탭을 처음 열 때만 약 2.6초. 냉장고 선그림 → 문 열림 → 재료 6개가 튀어나옴 → 명조 제목 → 위로 사라지며 메인 등장. 누르면 바로 건너뜀
- "움직임 줄이기" 설정을 켠 사용자에게는 시작 화면을 보여 주지 않음
- 그 밖의 전환은 0.15~0.5초로 짧게
- 효과음(`js/sound.js`, 음원 파일 없이 Web Audio로 만듦, 0.05~0.3초): 일반 버튼 "톡", 재료 넣기·고르기 "뽁", 해 먹었어요·냉장고에 넣기 "띠링", 별로예요·빼기 "툭". 기본 켜짐, 머리 오른쪽 스피커 버튼으로 끄면 그 기기에 기억. 시작 화면은 첫 터치 전이라 소리 없음

## 7. 하지 않을 것

- 바탕과 카드를 같은 연두색으로 칠하기 (경계가 흐려짐)
- #16A34A 위에 흰 글자 올리기, #16A34A를 넓은 면에 칠하기
- 그라데이션 버튼, 진한 그림자
- 이모지 (재료는 PNG 아이콘, UI는 Lucide)

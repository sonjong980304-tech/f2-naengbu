## 바뀐 파일

- `data/sample-fridge.json`: `master`에 14종 추가(40종). 샘플 냉장고에 콩나물(D-2), 양배추(D-6), 굴소스(D-120) 추가.
- `data/recipes.json`: 25개 → 39개. 새 재료마다 레시피가 1개 이상 있어서 추천에 실제로 나와요.
- `data/icon-map.json`: 14종 추가. `license: "own"`, `source: null`, `reference`(추가 이유, Flaticon 검색 링크) 필드가 붙어요.
- `data/copy.json`: 바뀐 것 없음.
- `icons/ingredients/`: 새 PNG 14개(512×512 투명). `icons/svg-source/`에 원본 SVG.
- 시안 HTML: 아이콘 출처 목록이 `source`가 있는 항목(Flaticon 26개)만 보여 주도록 한 줄 수정 → `.filter(v => v.source)`.

## Flaticon으로 바꾸고 싶을 때

검색 링크에서 아이콘을 고른 뒤, 같은 파일 이름으로 PNG를 덮어쓰고 `icon-map.json`의 `title`, `author`, `source`를 채우고 `license` 필드를 지우면 출처 목록에 자동으로 나와요. 검색 링크는 검색 결과 페이지일 뿐이라 특정 아이콘을 확인한 건 아니에요.
